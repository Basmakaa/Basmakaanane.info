# Add your photo

Save your headshot in this `public/` folder as **`avatar.jpg`** (or update the
path in `lib/data.ts` → `profile.avatar`).

- Recommended: a square-ish crop, at least 800×800px.
- The hero automatically frames it in a circular, glowing 3D portrait.
- Until you add it, a stylized silhouette placeholder is shown.
