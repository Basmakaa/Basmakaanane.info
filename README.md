# Basma Kaanane

A personal portfolio for Basma Kaanane — software engineer, founder, and
workshop host in Toronto.

Built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Editing

Copy lives in `lib/data.ts`: profile, about, selected work, and speaking.

The previous static page is kept at `public/legacy-site.html`.
